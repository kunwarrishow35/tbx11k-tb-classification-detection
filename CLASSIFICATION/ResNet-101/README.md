# ResNet-101 Multi-Label Chest X-Ray Classification Pipeline

## 1. Overview & Scope

This directory contains the complete, reproducible training, validation, and evaluation pipeline for **ResNet-101** on the **TBX11K** chest X-ray benchmark dataset. It directly mirrors the established workflow, output artifact schema, logging conventions, and evaluation suite of the project's [DenseNet-121 baseline](file:///c:/Users/kunwa/Desktop/IEEE%20RESEARCH/CLASSIFICATION/DensNet-121), while adapting architecture-specific hyperparameters informed by the official Torchvision ResNet reference recipe and hardware constraints (NVIDIA RTX 4050 Laptop GPU, 6 GB VRAM).

### Core Task
- **Dataset:** TBX11K Benchmark (Canonical 4,599 images: 3,219 train, 690 val, 690 test).
- **Task:** 2-output multi-label binary classification:
  - Output Index 0: `ActiveTuberculosis`
  - Output Index 1: `ObsoletePulmonaryTuberculosis`
- **Derived Categories:** Healthy `[0, 0]`, Active-only `[1, 0]`, Obsolete-only `[0, 1]`, Both `[1, 1]`.
- **Training Paradigm:** Trained strictly **from scratch** (`weights=None`). Zero transfer learning or pretrained weights.

## 2. Architectural Specification & Official Reference Comparison

| Feature | Original Paper / Caffe Repo (He et al., 2016) | Official Torchvision Reference Recipe | This Project Adaptation | Rationale / Distinction |
| :--- | :--- | :--- | :--- | :--- |
| **Model** | ResNet-101 (V1) | ResNet-101 (ResNet V1.5) | `torchvision.models.resnet101(weights=None)` | Torchvision uses ResNet V1.5 stride placement (downsampling stride in $3 \times 3$ `conv2` rather than $1 \times 1$ `conv1`), preserving information. |
| **Classification Head** | 1,000-class FC | 1,000-class FC | `model.fc = nn.Linear(2048, 2)` | Replaces ImageNet head with 2 independent binary logits. |
| **Parameters** | 44.55M (ImageNet-1K) | 44,549,160 (1000 classes) | **42,504,258** (2 classes) | Replacing `Linear(2048, 1000)` with `Linear(2048, 2)` reduces total parameters by 2,044,902. |
| **Compute at $512 \times 512$** | N/A ($224 \times 224$ crop: 7.8 GFLOPs) | 7.8 GFLOPs at $224 \times 224$ | **41.09 GMACs / 82.17 GFLOPs** | Measured via `thop` at native $512 \times 512 \times 3$ resolution ($1\text{ MAC} = 2\text{ FLOPs}$). |
| **Pretrained Weights** | Caffe converted models | `ResNet101_Weights.DEFAULT` | `None` (Random scratch init) | Strict from-scratch requirement for fair baseline comparison. |
| **Task / Loss** | Single-label Softmax Cross-Entropy | CrossEntropyLoss | `nn.BCEWithLogitsLoss()` on 2 raw logits | Independent Bernoulli multi-label modeling. No softmax. |
| **Optimizer** | SGD (momentum 0.9, weight decay 1e-4) | SGD (momentum 0.9, weight decay 1e-4) | `SGD(lr=0.01, momentum=0.9, weight_decay=1e-4, nesterov=False)` | Learning rate conservatively adapted from 0.1 to 0.01 due to single-GPU small-batch training. |

| **Epoch Budget** | ~120 epochs | 90 epochs (ImageNet) | **70 epochs max** (Patience: 20) | Matches DenseNet-121 project budget. Early stopping monitors validation macro-F1. |
| **Physical Batch Size** | 256 (across multi-GPU) | 32 per GPU (8 $\times$ V100 = 256) | **4** (fallback to 2 if OOM) | Hardware adaptation for 6 GB RTX 4050 VRAM. |

## 3. Mandatory Preprocessing vs. DenseNet-121 Baseline

> [!IMPORTANT]
> **Intentional Preprocessing Difference:**
> - **DenseNet-121 Baseline:** Used ImageNet mean (`[0.485, 0.456, 0.406]`) and standard deviation (`[0.229, 0.224, 0.225]`) normalization.
> - **ResNet-101 Experiment:** Uses **strictly NO normalization and NO data augmentation**. Images are converted to RGB, resized to $512 \times 512$ via bilinear interpolation, and converted to tensors via `transforms.ToTensor()`, scaling standard 8-bit pixel values directly into $[0.0, 1.0]$.

```python
from torchvision import transforms

def get_transforms():
    return transforms.Compose([
        transforms.Resize(
            (512, 512),
            interpolation=transforms.InterpolationMode.BILINEAR,
        ),
        transforms.ToTensor(),
    ])
```

## 6. Execution Instructions

### A. Pre-flight Smoke Test (2 Epochs)
To verify forward/backward passes, GPU VRAM allocation, loss finiteness, optimizer updates, checkpoint saving/reloading, and plotting without starting the full 70-epoch training:
```powershell
.\.venv\Scripts\python.exe CLASSIFICATION/ResNet-101/train.py --smoke-test
```

### B. Main Training Run (70 Epochs)
To launch the full from-scratch ResNet-101 training run (zero CLI arguments required):
```powershell
.\.venv\Scripts\python.exe CLASSIFICATION/ResNet-101/train.py
```
*(Optional arguments: `--batch-size 2` for OOM fallback, `--resume <path>` to resume from an interrupted checkpoint).*

### C. Test Evaluation
To evaluate the best checkpoint on the canonical test split (generates confusion matrices, JSON/CSV metrics, and detailed report):
```powershell
.\.venv\Scripts\python.exe CLASSIFICATION/ResNet-101/test.py
```
*(To specify an explicit checkpoint: `--checkpoint CLASSIFICATION/ResNet-101/outputs/train/best_model.pth`).*
